# 常见问答

## 通知发送失败怎么办？

1. 先通过 `GET /messages/{messageId}` 查看具体错误码
2. 常见原因：接收地址无效、模板变量缺失、触发限流
3. 修复后可调用重发接口重新发送

## 如何提高送达率？

- 邮件渠道建议配置 SPF / DKIM 记录
- 短信渠道需完成签名与模板审核
- 开启失败重试策略，系统会自动按退避间隔重试

## API Key 泄露了怎么办？

立即在控制台吊销旧 Key 并生成新 Key。吊销后旧 Key 立即失效，不影响历史消息。

## 支持多少 QPS？

默认每个账号 100 QPS。如需更高配额，可在控制台提工单申请扩容。

## 自部署版本和云服务有区别吗？

功能上保持一致，自部署版本的数据完全存储在你自己的服务器上；云服务由我们负责运维和可用性保障。

## 还有其他问题？

请通过控制台工单系统联系我们，一般 1 个工作日内回复。
